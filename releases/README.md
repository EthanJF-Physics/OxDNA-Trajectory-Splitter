# Release-candidate artifacts

Phase 6 produces an installable wheel and a source archive for review and
controlled use. The maintained deliverable is the installable Python package;
a standalone script is not included.

The project owner confirms they created the software. No software license is
included or selected, by project-owner decision. The absence of a license does
not place the software in the public domain or grant open-source reuse rights;
see `LICENSE-STATUS.md`.

Run release tests on each platform that will be advertised as supported. The
current verification scope and known limitations are documented in
`docs/PHASE6_RELEASE_REPORT.md`.
